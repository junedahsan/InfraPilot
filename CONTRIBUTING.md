# Contributing

Thank you for improving InfraPilot.

- Keep the default behaviour local and read-only.
- Add tests for changed behaviour and run `python -m pytest`.
- Explain new checks in the README, including permissions and privacy implications.
- Use fictional or redacted data in examples, issues, and pull requests.
- Do not add telemetry, cloud uploads, credentials, or automated remediation without clear user opt-in and documentation.
